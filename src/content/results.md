## How to read a result on this page

Every headline result, including every failed one, uses the same eight fields,
in the same order:

| Field               | What goes in it                                 |
| ------------------- | ----------------------------------------------- |
| **Question**        | The question the experiment was built to answer |
| **Experiment**      | A small schematic, not a protocol               |
| **Evidence**        | The plot, gel or image itself                   |
| **Controls + n**    | Visible, not buried                             |
| **Result**          | One or two sentences                            |
| **Interpretation**  | One or two sentences                            |
| **Limitation**      | One sentence, honestly                          |
| **What it changed** | A link into [Engineering](/engineering)         |

And every result carries one status marker:

🟢 Supported · 🟡 Preliminary · 🔴 Did not work or inconclusive ·
🔵 Modelled prediction

Learn those two conventions once and the rest of this wiki reads the same way.
